# worth it?

One-page landing site for **Worth It?** — an AI tool that tells thrift resellers whether an item is worth flipping.

Built with Next.js (App Router). No other dependencies.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import the GitHub repo at https://vercel.com/new — Vercel detects Next.js automatically, no settings needed.
